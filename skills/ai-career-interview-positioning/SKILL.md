# AI Career Interview Positioning

## Scope

Use the accepted diagnosis or Learning Handoff, target JD, and selected Case Handoffs when available. Return only interview positioning and answer strategy. Do not repeat the full diagnosis or create a learning plan.

## Intake

Use the primary role family, top evidence, real gaps, claim boundaries, target JD, and verified Case Handoffs. Ask for the target JD or interview stage only when it would materially change the narrative.

## Strategy

- Lead with the user's strongest credible through-line, not a list of tools.
- State a real gap once, then bridge it with concrete learning, a case, or decision practice. Never inflate claims.
- Turn likely concerns into proactive transition statements.
- Prepare questions that reveal the team's task-success definition, human handoff, model trade-offs, and evaluation practice.

## Output

This is normally the end of the toolkit flow. Its output is user-facing interview material; no next-Skill handoff is required unless the user chooses to return to learning or case refinement.

Return only:

1. 60-second opening.
2. Three proof points to lead with.
3. Three anticipated concerns and proactive bridges.
4. Two-minute primary-case story.
5. Targeted answers for five likely questions.
6. Three questions to ask the interviewer.

Present the first draft in chat for collaboration. Create an editable interview-preparation Markdown file only when the user accepts it or requests an artifact. Do not turn text answers into visual cards unless the user needs a comparison or memory aid.
