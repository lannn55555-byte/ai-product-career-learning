# AI 产品职业与学习工具包

这是一个只包含 Skills 的插件，帮助用户转向 AI 相关设计、UX、产品、Agent 或体验岗位，或系统学习 AI 产品知识。它会根据用户的真实经历、目标岗位要求和学习偏好生成个性化路线，并通过对话式学习帮助用户建立知识连接。

## 包含的 Skill

- `ai-career-transition-planner`：职业方向、经历证据与能力缺口诊断。
- `ai-career-sprint-plan`：个性化学习路线，以及 AI 主线和产品基础的双轨安排。
- `adaptive-ai-learning-coach`：多轮对话学习、发散问题处理、应用题、进度与学习日志。
- `ai-career-case-strategy`：将一个真实项目整理为可信案例。
- `ai-career-interview-positioning`：准备自我介绍、面试回答和反问。

## 使用原则

默认采用“对话优先 + 阶段性 Markdown 文件”：学习和协作发生在对话中；只有在诊断确认、学习路线确认、重要学习节点、案例确认或面试材料确认后，才生成可编辑文件。所有交接信息都由用户可见、可纠正，不传递完整对话或隐藏推理。

AI 主线与产品基础分别记录进度，但会通过明确的设计问题连接：例如 RAG 与事实来源/信息架构、Tool Calling 与服务蓝图/决策表、Agent 状态与用户旅程、评估与指标研究。

## 隐私

不要提交真实简历、学习日志、面试记录、联系方式、密钥或公司保密信息。公开示例必须匿名，并保持个人贡献与团队贡献的边界。
